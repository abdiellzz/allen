ALLEN Portable

1. Extrae TODO el contenido del ZIP en una carpeta o memoria USB.
2. Ejecuta ALLEN.exe.
3. No muevas solo el EXE: la carpeta _internal también es necesaria.
4. Los perfiles, progreso, backups y configuración se guardan en ALLEN-Data junto a la aplicación.
5. Puedes mover la carpeta completa a otro equipo Windows x64 y conservar esos datos.
6. El modelo GGUF y llama.cpp no se incluyen. Puedes configurarlos desde ALLEN o usar el modo demo.

Para cerrar ALLEN usa el botón "Cerrar ALLEN" de la ventana del launcher.
