ALLEN Portable

1. Extrae TODO el contenido del ZIP en una carpeta o memoria USB.
2. Ejecuta ALLEN.exe.
3. No muevas solo el EXE: la carpeta _internal también es necesaria.
4. En la primera apertura, copia el Machine ID y solicita un archivo .license válido.
5. Importa la licencia desde la pantalla de activación.
6. Los perfiles, progreso, backups, licencia y configuración se guardan en ALLEN-Data junto a la aplicación.
7. El modelo GGUF y llama.cpp no se incluyen. Puedes configurarlos desde ALLEN o usar funciones sin IA generativa.

IMPORTANTE SOBRE MOVIMIENTO ENTRE EQUIPOS:
- Puedes mover los datos, pero la licencia está vinculada al Machine ID.
- Si ejecutas el Portable en otra computadora, puede requerir una licencia emitida para ese nuevo Machine ID.

Para cerrar ALLEN usa el botón "Cerrar ALLEN" de la ventana del launcher.

Para borrar aplicación y datos locales usa "Eliminar ALLEN completamente.bat" y escribe BORRAR cuando se solicite.
