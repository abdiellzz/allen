ALLEN License Manager

Este programa es PRIVADO y no debe distribuirse a clientes.

Seguridad:
- El ejecutable NO contiene la clave privada.
- Coloca license_private_key.pem junto a ALLEN-License-Manager.exe.
- Nunca subas license_private_key.pem a GitHub, Drive público, correo masivo o al instalador de ALLEN.
- ALLEN comercial solo contiene la clave pública.

Flujo:
1. El cliente instala ALLEN y copia su Machine ID.
2. Abre ALLEN License Manager.
3. Escribe Cliente, Machine ID, Plan y 30 días.
4. Genera el archivo .license.
5. Envía únicamente el .license al cliente.
6. Para renovar, carga la licencia anterior y genera una renovación.

Cada instalación puede tener perfiles, estudiantes y profesores ilimitados.
