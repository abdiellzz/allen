# ¿Qué ocurre cuando le preguntas a Allen?

La interfaz envía tu pregunta al servidor local de Allen. Este prepara instrucciones educativas y las envía a un modelo en tu dispositivo. El modelo genera texto y Allen te lo muestra.

## IA, modelos y aprendizaje

Inteligencia artificial es un campo que busca crear sistemas capaces de realizar tareas que requieren capacidades como reconocer patrones o producir lenguaje. El aprendizaje automático permite ajustar un modelo con ejemplos. Un modelo de lenguaje grande, o LLM, aprende patrones del texto durante su entrenamiento.

Usar Allen no significa que el modelo esté volviendo a entrenarse con tus conversaciones. El historial permite mantener contexto, pero no cambia sus pesos.

## Local significa aquí

Un modelo local se ejecuta en este dispositivo. No necesita enviar tus preguntas a una nube para generar respuestas. Descargarlo e instalar sus herramientas por primera vez sí requiere obtener archivos.

## Las respuestas no siempre son ciertas

Un modelo puede producir una afirmación falsa con tono convincente. Esto suele llamarse alucinación. Para datos importantes, comprueba una fuente o pregunta a tu docente.

## Actividad

Inventa una pregunta cuyo resultado puedas comprobar con lápiz y papel. Hazla al modelo y compara. ¿Explica bien el procedimiento?
